# Specification

## Summary
**Goal:** Build Sansi App Collector - a web app for manually collecting, organizing, and exporting message conversations to PDF format.

**Planned changes:**
- Create conversation management system with ability to add, view, and switch between multiple conversations
- Implement manual message input interface with sender name, message text, and timestamp fields
- Display messages chronologically in a chat-like interface with message bubbles
- Add PDF export functionality with chat-style layout, conversation title, and date range
- Implement search feature to filter messages by text content with highlighting
- Enable date range selection for PDF exports
- Support exporting multiple conversations into a single PDF document
- Add dark mode toggle with persistent theme preference
- Implement PIN lock functionality for app access with secure backend storage
- Remove PlatformLimitations and WebAlternatives sections, replacing with conversation interface
- Maintain minimalist design with white background and coral accent color

**User-visible outcome:** Users can manually create and manage message conversations, add individual messages with timestamps, search through conversations, toggle dark mode, secure the app with a PIN, and export conversations to well-formatted PDFs with flexible date range and multi-conversation options.
